# BIM Clash Matrix — النسخة المبسّطة (Lite)

موقع ثابت (HTML + JavaScript بدون أي مكتبات أو build) يُنشر على **GitHub Pages**. كل المعالجة تتم داخل المتصفح. GitHub هو التخزين وسجل التدقيق والصلاحيات.

## التشغيل
1. أنشئ مستودعاً على GitHub وارفع محتويات هذا المجلد.
2. Settings ← Pages ← Source: **GitHub Actions**. أول push على `main` ينشر الموقع بعد نجاح الاختبارات.
3. افتح الموقع ← **استيراد** ← اختر ملف Excel ← **الرموز** (اختر الملف لكل رمز) ← **توليد الاختبارات** ← راجع **مجموعات البحث** ← **التحقق** ← **التصدير**.
4. للمزامنة: صفحة **GitHub** ← أدخل owner/repo وToken (Fine-grained، صلاحية Contents على مستودع واحد).

محلياً: `cd web && npx http-server .` (أو أي خادم ثابت) ثم افتح `http://localhost:8080`. الاختبارات: `node --test web/tests/*.test.mjs` (Node 22+).

## ما الذي تم اختباره فعلاً
- منطق النواة (قراءة xlsx، التوليد، التفاوتات الدقيقة، التحقق، كتابة XML، ZIP): اختبارات `node --test` ناجحة على ملف عيّنة **اصطناعي**.
- الواجهة: شُغّلت في Chromium (Playwright) على ملف العيّنة: استيراد ← توليد ← كل الصفحات ← تنزيل الحزمة، بدون أخطاء في الكونسول.

## ما لم يُختبر (مهم)
- **صيغة XML الخاصة بـ Navisworks غير مُتحقَّق منها.** كُتبت من الذاكرة ومعلَّمة UNVERIFIED. لم يُستورد أي ملف إلى Navisworks. استخدم صفحة التصدير لمقارنة البنية بملفات حقيقية صدّرتها أنت، ثم جرّب الاستيراد وأعد فتح الملف قبل أن تعتبرها صحيحة.
- مزامنة GitHub لم تُجرَّب على GitHub حقيقي.
- الإضافة داخل Navisworks (`addin/`) هيكل فقط، غير مترجم.
- ملف Excel حقيقي بتنسيق مختلف قد يحتاج ضبطاً في الاستيراد.

## البنية
`web/js/core` منطق بحت قابل للاختبار · `web/js/views` الصفحات · `web/tests` الاختبارات · `.github/workflows` النشر والاختبار.
